DMEXCO 2026 — Conference Agenda

✨ Let AI pick sessions for me

Your key and interests are sent directly from your browser to api.anthropic.com — nothing passes through any other server. The whole agenda (~440 sessions) goes into one request, so expect roughly $0.10–0.35 per run depending on model. Get a key at console.anthropic.com.

Most keys need no Workspace ID. A legacy sk-ant-api03-… key, or any key created scoped to a workspace, carries its workspace — leave the field blank. Only fill it in for a Personal / service-account key that is not workspace-scoped (the error says anthropic-workspace-id is required); the simpler fix is to use a workspace-scoped key instead. Non-default workspace IDs (wrkspc_…) appear in the ID column of Settings → Workspaces; the Default workspace's ID is not shown anywhere in the console.
